    多模态 API

    “凡自然相连的事物，皆应结合教授”——约翰·阿莫斯·夸美纽斯，《视觉世界》，1658 年

    人类处理知识时，会同时利用多种数据输入模式。我们的学习方式以及所有经历都是多模态的。我们不仅仅拥有视觉、听觉或文本感知。

    与这些原则相反，机器学习往往专注于针对单一模态量身定制的专用模型。例如，我们开发了用于文本转语音或语音转文本任务的音频模型，以及用于目标检测和分类等任务的计算机视觉模型。

    然而，一种新的多模态大语言模型浪潮正在兴起。例如，OpenAI 的 GPT、Google 的 Gemini、Anthropic 的 Claude，以及开源项目 Llama、LLaVA 和 BakLLaVA 等，均能够接受多种输入，包括文本、图像、音频和视频，并通过整合这些输入来生成文本响应。

    多模态大语言模型（LLM）的功能使模型能够结合图像、音频或视频等其他模态来处理并生成文本。

    Spring AI 多模态

    多模态是指模型同时理解和处理来自多种来源信息的能力，包括文本、图像、音频以及其他数据格式。

    Spring AI 消息 API 提供了支持多模态大语言模型所需的所有抽象。

    UserMessage 的 `content`` 字段主要用于文本输入，而可选的 `media`` 字段则允许添加一种或多种其他模态的内容，例如图像、音频和视频。 `MimeType` 指定了模态类型。 根据所使用的 LLMs，`Media`` 数据字段可以是作为 `Resource`` 对象的原始媒体内容，也可以是内容的 `URI``。

    媒体字段目前仅适用于用户输入消息（例如 UserMessage），对系统消息并无意义。AssistantMessage 包含 LLM 的响应，仅提供文本内容。若要生成非文本的多模态输出，请使用专用的单模态模型之一。*

    例如，我们可以将以下图片（multimodal.test.png）作为输入，并要求 LLM 解释它所看到的内容。

    对于大多数多模态大语言模型，Spring AI 的代码大致如下所示：

    var imageResource = new ClassPathResource("/multimodal.test.png");

var userMessage = UserMessage.builder()
    .text("Explain what do you see in this picture?") // content
    .media(new Media(MimeTypeUtils.IMAGE_PNG, this.imageResource)) // media
    .build();

ChatResponse response = chatModel.call(new Prompt(this.userMessage));

    或者使用流利的ChatClientAPI：

    String response = ChatClient.create(chatModel).prompt()
		.user(u -> u.text("Explain what do you see on this picture?")
				    .media(MimeTypeUtils.IMAGE_PNG, new ClassPathResource("/multimodal.test.png")))
		.call()
		.content();
