    AI 元数据

    使用人工智能（例如 OpenAI 的 ChatGPT）会消耗资源，并生成由 AI 提供商根据通过 API 向 AI 发出的使用情况和请求所返回的指标。 消费通常以给定时间段内（如每月）发出的请求数或使用的令牌数为单位，AI 提供商据此衡量此类消费并重置限制。 您的速率限制在您与 AI 提供商签约时即由所选计划直接决定。例如，您可以通过点击链接查看 OpenAI 的速率限制和计划详情。

    为帮助您深入了解 AI（模型）的使用情况和总体使用情况，Spring AI 提供了一个 API，用于检查 AI 提供商在其 API 中返回的元数据。

    Spring AI 定义了三个主要接口用于检查这些指标：GenerationMetadata、RateLimit 和 Usage。所有这些接口都可以通过从 AI 请求返回并发起的 ChatResponse 进行程序化访问。

    GenerationMetadata interface

    GenerationMetadata 接口的定义如下：

    GenerationMetadata 接口
    interface GenerationMetadata {

	default RateLimit getRateLimit() {
		return RateLimit.NULL;
	}

	default Usage getUsage() {
		return Usage.NULL;
	}

}

    当通过 AI 提供商的 API 发起 AI 请求并返回 AI 响应时，Spring AI 会自动创建一个GenerationMetadata实例。您可以通过以下方式从ChatResponse中获取 AI 提供商元数据：

    从ChatResponse中获取对GenerationMetadata的访问权限。
    @Service
class MyService {

	ApplicationObjectType askTheAi(ServiceRequest request) {

        Prompt prompt = createPrompt(request);

        ChatResponse response = chatModel.call(prompt);

        // Process the chat response

        GenerationMetadata metadata = response.getMetadata();

        // Inspect the AI metadata returned in the chat response of the AI providers API

        Long totalTokensUsedInAiPromptAndResponse = metadata.getUsage().getTotalTokens();

        // Act on this information somehow
	}
}

    您可能想象，可以利用人工智能对自身的 Spring 应用程序实施速率限制，或者以自动化、智能且实时方式限制影响令牌使用量的Prompt大小。

    至少，您可以简单地收集这些指标来监控和报告您的使用情况。

    RateLimit

    RateLimit 接口提供了访问 AI 提供商在您发出 AI 请求时返回的实际 API 使用信息。

    RateLimit interface
    interface RateLimit {

	Long getRequestsLimit();

	Long getRequestsRemaining();

	Duration getRequestsReset();

	Long getTokensLimit();

	Long getTokensRemaining();

	Duration getTokensReset();

}

    `requestsLimit` 和 `requestsRemaining` 可让您了解在所选 AI 提供商计划（注册时选择）的给定时间范围内，总共可以发起多少 AI 请求以及剩余配额。`requestsReset` 返回一个 `Duration`，表示根据您选择的计划，时间范围到期且限制重置前所剩的时间。

    `tokensLimit`、`tokensRemaining` 和 `tokensReset` 这些方法与请求相关的方法类似，但专注于令牌限制、余额和重置。

    可以从GenerationMetadata中获取RateLimit实例，如下所示：

    从GenerationMetadata中获取对RateLimit的访问权限。
    RateLimit rateLimit = generationMetadata.getRateLimit();

Long tokensRemaining = this.rateLimit.getTokensRemaining();

// do something interesting with the RateLimit metadata

    对于 OpenAI 等 AI 提供商，速率限制元数据会通过其（REST）API 返回在 HTTP 响应头中，这些响应头可通过 HTTP 客户端（如 OkHttp）进行访问。

    由于此操作可能会产生高昂的成本，必须显式启用速率限制 AI 元数据的收集。您可以在 Spring Boot 的 application.properties 文件中通过 Spring AI 属性来启用此功能；例如：

    从 AI 元数据中启用 API 速率限制收集
    # Spring Boot application.properties
spring.ai.openai.metadata.rate-limit-metrics-enabled=true

    Usage

    如上所示，Usage 数据可以从 GenerationMetadata 对象中获取。Usage 接口的定义如下：

    Usage interface
    interface Usage {

	Long getPromptTokens();

	Long getGenerationTokens();

	default Long getTotalTokens() {
		return getPromptTokens() + getGenerationTokens();
	}

}

    方法名称一目了然，但它们告诉您 AI 处理 `Prompt` 并生成响应所需的标记。

    `totalTokens` 是 `promptTokens` 和 `generationTokens` 的总和。Spring AI 默认会计算该值，但相关信息也会从 OpenAI 返回的 AI 响应中获取。
